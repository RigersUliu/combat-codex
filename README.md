# FightIQ Hub

FightIQ Hub is a React + Vite web app focused on combat-sports education, quizzes, myth busting, and community interaction.

## Features

- Multi-page app with React Router
- Martial art recommendation quiz
- Fight IQ scenario quiz
- Myth buster cards
- Gorilla simulator (fictional/humor)
- Community forum with CRUD
- Local fight streams with comments persisted in localStorage

## Tech Stack

- React
- Vite
- React Router DOM
- JavaScript (ES modules)
- CSS

## Project Structure

```txt
src/

  App.jsx
  main.jsx
  styles.css
```

## Getting Started

### Prerequisites

- Node.js 20.19+ or 22.12+
- npm

### Install

```bash
npm install
```

### Run (development)

```bash
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
